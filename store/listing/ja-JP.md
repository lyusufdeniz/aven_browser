# Aven Browser — Google Play ストア掲載文（日本語）

## App name (max 30 characters)

Aven Browser: テレビとスマホ

## Short description (max 80 characters)

リモコンのカーソル操作、広告ブロック、内蔵プレーヤーを備えたテレビ＆スマホ用の高速ブラウザ

Alternatives:
- テレビではリモコンのカーソルで、スマホでもそのままウェブを快適に
- Android TV のリモコン向けに作られたブラウザ。スマホアプリも付属

## Full description (max 4000 characters)

Aven は、テレビの画面を第一に考えて作られたウェブブラウザです。リモコンでページ上のカーソルを動かし、OK でクリック。同じ Aven がスマホでも使え、すっきりしたスタート画面、タブ、リーディングリスト、テレビ用リモコン機能を備えています。

📺 テレビでかんたんブラウジング
• リモコンカーソル：十字キーで移動、OK でクリック、上端で上を押すとアドレスバーへ
• リモコンのマイクで音声検索
• 大画面向けのスタートページ：動画、ライブ、音楽サイトにワンクリックでアクセス
• 続きから視聴：見ていた動画を中断したところから再開
• サイトをデスクトップ版・モバイル版・Android TV 版で表示

▶️ Aven プレーヤー内蔵
• ページ内の動画を Aven プレーヤーで全画面再生
• 再生速度、画質の選択、字幕に対応
• 字幕のサイズ、色、背景を選べます
• スマホでは全画面表示、画面回転、ピクチャー・イン・ピクチャーに対応

📱 スマホでも速く、すっきり
• 中央配置のスタート画面、フローティングツールバー、サイトアイコン付きのタブ
• 閉じたタブをワンタップで元に戻す
• リーダーモードと「あとで読む」：ページを保存してオフラインで読める
• ページ内検索、ズーム、リンクや画像の長押しメニュー
• ライト・ダーク・システム連動のテーマ

📡 スマホとテレビを連携
• スマホをテレビのリモコンに：ドラッグでカーソル移動、2本指でスクロール
• スマホのキーボードでテレビに文字入力
• スマホで見ているページや動画を、テレビの Aven に送信
• デバイス同士は同じ Wi-Fi ネットワーク上でのみ接続

🛡️ プライバシーと管理
• シークレットタブ：開いたページは履歴に保存されません
• アプリ内リストによる広告ブロック（任意）。ネットワーク設定の変更や追加の権限は不要
• サイト設定：位置情報、カメラ、マイク、通知、自動再生の許可をサイトごとに管理
• 接続の安全性と証明書の詳細を表示
• アカウント不要、広告なし、トラッキングなし

📚 ライブラリとデータ
• ブックマーク、履歴、ダウンロード、リーディングリストを一か所に
• Chrome、Firefox などのブラウザから HTML ファイルでブックマークをインポート
• ブックマークと履歴をエクスポート
• 履歴の消去：過去15分、1時間、1日、1週間、4週間、全期間から選択

⚙️ その他の機能
• デフォルトの検索エンジン：Google、DuckDuckGo、Bing、Yandex
• 古いテレビボックスでもページが軽快に動くライトモード
• Aven をデフォルトのブラウザに設定
• ダウンロードとファイルの表示

Aven はアカウント不要です。履歴、ブックマーク、設定はすべてお使いのデバイス内に保存されます。
